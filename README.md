# Catálogo de Mídias — Jornalismo TV Cultura

Desenvolvimento voluntário de uma plataforma open-source para produtores do jornalismo da TV cultura.

visando algumas dificuldades para encontrar imagens no catalogo da casa, resolvi desenvolver essa plataforma onde pudessem ser encontrados facilmente imagens de diversos programas do jornalismo, a idéia é que todos os materiais fiquem disponiveis em um unico lugar para que seja facilmente encontrado por todos.

https://fffelpe.github.io/catalogo/index.html
